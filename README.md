# 🤖 Mail Automator Bot (IMAP to Telegram)

Надежный Telegram-бот на Python для автоматического мониторинга электронной почты (по протоколу IMAP), извлечения PDF-вложений и их мгновенной пересылки в мессенджер. 

Проект решает реальную бизнес-задачу по маршрутизации документов (счетов, актов, штрафов) и включает **жесткую защиту от дублирования сообщений** при сбоях почтового сервера.

## 🔥 Ключевые возможности
- **IMAP Мониторинг:** Автоматическое чтение непрочитанных писем от заданных отправителей.
- **Умный фильтр:** Извлекает только `.pdf` документы.
- **MD5-Хэширование:** Бот вычисляет уникальный цифровой отпечаток (`hashlib.md5`) каждого файла и сохраняет его на жесткий диск. Это гарантирует, что даже если почтовый сервер зависнет и будет отдавать одно и то же письмо бесконечно, бот **никогда не отправит дубликат**.
- **Сортировка на сервере:** После успешной обработки бот автоматически перемещает письма в нужные папки на почтовом сервере или помечает их как прочитанные.
- **Многопоточность:** Обработка почты и работа Telegram-бота разнесены по разным потокам (`threading`).

## 🛠 Стек технологий
- **Python 3**
- `pyTelegramBotAPI` (telebot) — для взаимодействия с Telegram API
- `imap_tools` — для удобной работы с почтовыми ящиками
- `hashlib` & `os` — для работы с файловой системой и генерации отпечатков

## ⚙️ Настройка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/tyuzdeev/mail-automator-bot.git](https://github.com/tyuzdeev/mail-automator-bot.git)
   cd mail-automator-bot

2. Установите зависимости:

Bash
pip install pyTelegramBotAPI imap_tools

3.
Откройте mail_bot.py и подставьте свои данные в блок настроек:

EMAIL_LOGIN и EMAIL_PASSWORD (используйте пароль для внешних приложений)
TG_TOKEN (от BotFather)
TG_CHAT_ID (ваш ID в Telegram)

4. 
Запустите бота:

Bash
python3 mail_bot.py
